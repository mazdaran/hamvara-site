BEFORE YOU START

A few useful answers.

Clear expectations make a better first experience.

Which files does SKU Bridge support?+

The launch version supports Excel (.xlsx and .xls) and CSV product lists. It includes column mapping and a review step before export. The public beta linked above is an earlier version.

Will the output work with every ERP?+

Destination systems use different import templates. Review column names, required fields and formats against your ERP's template. Universal compatibility is not guaranteed.

What happens to leading zeros in product codes?+

The launch Excel exporter writes SKU and barcode values as text. If a source file has already lost a leading zero, the software cannot reliably reconstruct it; review the original data.

Can I buy a subscription here today?+

No. This is a review version of the launch website. Prices are visible for review; payment and customer account activation still need to be enabled.

Are SKU Bridge and MRP one subscription?+

They are separate products and plans. This preview shows SKU Bridge monthly or annually and Hamvara MRP SaaS annually.

Where can I get help?+

Email info@hamvara.com or use one of the contact links below. For an MRP demo, tell us about your current stock, purchasing and production workflow.
