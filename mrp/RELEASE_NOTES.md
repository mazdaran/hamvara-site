# Hamvara MRP 0.47.0

This stable candidate packages the governed MRP II operating chain, factory acceptance, controlled go-live, hypercare, and production operations baseline.

## Verification

- Run `npm test` from `worker/` and retain the result with the release evidence.
- Confirm the displayed application version, data schema, release manifest, and artifact checksum.
- Complete every Release Package document gate before publication.

## Compatibility

Existing Hamvara JSON data is normalized forward to schema 64. Always create and verify a full backup before migration. LIFO remains available only under the US GAAP accounting profile.

## Release status

Internal release packaging does not constitute external certification. Customer production activation remains subject to Factory Acceptance and Go-Live approval.
